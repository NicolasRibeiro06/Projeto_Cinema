## 💡 Sobre o Projeto

O **Projeto Cinema** tem como objetivo simular e automatizar uma biblioteca de filmes. O sistema organiza o catálogo de filmes, atores e cadastro dos mesmos.


---

## ✨ Funcionalidades

- [x] **Catálogo de Filmes:** Listagem de filmes e futuros lançamentos (sinopse,  classificação indicativa e gênero).
- [x] **Painel Administrativo:** Cadastro, edição e remoção de filmes.
